# Page MAGUISSI BIRR pour le site SES

Le fichier `maguissi-birr-landing.html` est une maquette HTML autonome, responsive et accessible. Il contient des illustrations vectorielles intégrées (SVG), les coordonnées publiques de SES, un lien vers les versions publiées et une mention honnête du fait que la synchronisation serveur n'est pas encore active.

## Intégration WordPress proposée

1. Créer une sauvegarde du site SES et une page brouillon intitulée « MAGUISSI BIRR ».
2. Vérifier que le thème et les extensions du site permettent de coller le contenu HTML dans un bloc « HTML personnalisé ». Le site peut filtrer les balises `style`; dans ce cas, déplacer le CSS dans le CSS additionnel du thème enfant ou dans une feuille de style dédiée.
3. Adapter le lien de téléchargement vers la release validée et stable dès qu'elle sera disponible.
4. Vérifier les liens, le rendu mobile, le contraste, les liens téléphoniques et e-mail, puis faire valider le contenu par SES.
5. Publier seulement après validation de SES.

## Important

Ce fichier est un livrable de préparation, pas une page déjà publiée sur le site SES. Aucun accès administrateur au site n'a été utilisé. Il ne collecte pas de signalements et ne prétend pas que le serveur SES est déjà connecté à l'application.
